# Rust Embedded Workbench — signed update channel

This dedicated Git branch is the distribution channel for qualified **Eclipse p2** updates of [Rust Embedded Workbench](https://github.com/niwantha33/rust-embedded-workbench).

**BOOTSTRAP_ONLY — NO PUBLISHED RELEASE**

This branch does not contain a valid update until the authenticated CI release publisher has committed both `channel.properties` and its Ed25519 detached signature `channel.sig` and an immutable `releases/<version>/` directory.

Do not install or download anything from this branch manually. Source code and pull requests belong on `main`. Future release files are generated by CI only, after build, provisioning and signing checks. Never commit signing private keys here.

Channel protocol: [Secure Updates](https://github.com/niwantha33/rust-embedded-workbench/blob/main/docs/SECURE_UPDATES.md).
