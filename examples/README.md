# Firmware examples

No firmware examples are shipped yet. The first proposed target is TI LP-MSPM0G3507 with Embassy, followed by STM32 NUCLEO-F446RE and RP2040 Pico.

Each example must pin toolchain and HAL versions, target triple, linker configuration, physical board package and expected output. A source example without build/flash/debug evidence is not considered hardware-qualified.
